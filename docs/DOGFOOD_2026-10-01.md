# Native Mac dogfood and cross-platform build receipt

The owner confirmed Apple silicon with macOS 26. The first Mac app is published:
https://github.com/falseywinchnet/swiftedit/releases/tag/v0.2.0-dogfood.20261001

Application source: `5d7d1c79f8450f68019edf43c64e50e2be9aaa7b`.
Provider source: `6def54ad2bf2089b57c09337c0b3f82cc1178187`.
Both repositories remain private.

Native SwiftEdit CI passed all three jobs:
https://github.com/falseywinchnet/swiftedit/actions/runs/36853053157

| Platform | Suites | Total test time | Native lifecycle |
|---|---:|---:|---|
| Windows x64 | 17/17 | 5.67 s | Passed |
| macOS ARM64 | 16/16 | 2.09 s | Passed |
| Linux x64 | 16/16 | 5.81 s | Passed |

The native lifecycle fixture exercises open/edit/save, Find/Replace/undo, owned
dialogs, picker cancel/reopen, conflict save and clean shutdown. Test-suite times
are not interactive latency measurements. Earlier Mac failures exposed a
Windows-only hard-link fixture and an application startup/picker issue with
system directory aliases. The fixes use standard hard-link creation and resolve
the picker starting directory before granting it. Document file paths retain
their existing no-follow validation.

Provider CI independently built/tested the matching GUI.Forms Application and
picker SDKs, installed each to a new prefix and configured/linked independent
consumers: https://github.com/falseywinchnet/file_manager/actions/runs/36850852233
All downloaded archive hashes and installed-content hashes were verified with
`tools/Verify-Sdk-Archive.py` before mirroring into the pinned dependency release.
This does not assert availability of new prepared-text APIs.

Mac packaging copied fonts and notices, resolved private libraries, checked load
paths, ad-hoc signed and verified the bundle. The packaged process stayed alive
for five seconds with a disposable text fixture and without inherited SDK font
or dynamic-library overrides. The runner was macOS 26.6.2 ARM64. Mach-O load
commands in the downloaded app and library specify macOS 26.0 minimum. Older
macOS versions and Intel Macs were not tested. Developer ID signing and Apple
notarization are not configured.

Published ZIP: `SwiftEdit-macos-arm64-5d7d1c79f845.zip`.
SHA-256: `27a2f83b1b0baebc8073c0d0f2b97de247c71bffb478e4e691b8e401efe84d36`.
The downloaded executable matched the build manifest, and GitHub's published
asset digest matches the verified ZIP. The release also includes a manifest,
checksum file and README.

This is an early dogfood build. GUI limits remain 1 MiB of UTF-8 text and 4096
UTF-8 bytes per logical line. Shared-session GUI migration, larger-file GUI
interaction, other expanded objectives and the final measured lag/bug review
remain open. Existing frozen SDKs and dogfood copies were preserved.
